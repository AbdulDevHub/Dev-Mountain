Welcome to the Resources hub — a structured collection of practical references, learning material, and workflow tools for modern development.

This is not a reading list. It’s a working index.

Here you’ll find focused references across frontend development, scripting, tooling, system setup, and design exploration. Each section is intended to be used when you’re actively building, debugging, or improving your workflow — not just browsing.

## Philosophy

Most resources pages become graveyards of bookmarks.

This one is designed to stay active:

- quick to scan
- easy to return to during real work
- structured around intent, not topics
- optimized for reuse rather than discovery overload

If something feels hard to find here, it usually means it should be reorganized or broken into a more specific reference page.
